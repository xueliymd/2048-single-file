# 2048 · 单文件网页版

一个零依赖的 2048 小游戏，整个游戏只有 `index.html` 一个文件（约 10KB），不引用任何外部 CDN、字体或图片资源，双击即可在浏览器里玩。

最初是为了验证「单文件静态页面能否在极简环境下完整运行」而写的，后来补齐了键盘、触屏、最高分记录等细节，作为一个可长期把玩的轻量作品。

## 玩法

- **方向键 / WASD**：上下左右移动方块
- **触屏滑动**：手机上直接滑动屏幕
- 相同数字的方块相撞会合并，目标是拼出 **2048**
- 达到 2048 后仍可继续，直到无法移动

## 功能

| 功能 | 说明 |
|---|---|
| 分数统计 | 实时显示当前得分 |
| 最高分 | 用 `localStorage` 持久化，刷新/关闭后仍保留 |
| 撤销式重开 | 点击「重新开始」立即重置棋盘与分数（最高分不清） |
| 键盘操作 | 方向键与 WASD 双套键位，`preventDefault` 避免页面滚动 |
| 触屏操作 | `touchstart`/`touchend` 计算滑动方向，阈值过滤误触 |
| 动画过渡 | 方块移动与合并使用 CSS `transition`，不依赖动画库 |
| 自适应布局 | 棋盘宽度用 `min(92vw, 420px)`，桌面与手机同一套样式 |
| 结束判定 | 无空格且四邻无相同数字时弹出结束浮层，可一键重开 |

## 技术实现

- **纯原生**：HTML + CSS + JavaScript，无框架、无构建步骤、无依赖
- **单一文件**：样式内联在 `<style>`，逻辑内联在 `<script>`，便于分发与部署
- **状态模型**：4×4 二维数组存数字，0 表示空格；每次移动先做「压缩 → 合并 → 再压缩」，再随机在空位生成 2 或 4
- **渲染方式**：DOM 节点复用，只更新文本与类名，避免整棵树重建
- **配色**：沿用 2048 原版的米色系（`#faf8ef` / `#bbada0` / `#776e65`），降低视觉干扰

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

如果需要一个本地 HTTP 服务：

```bash
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

部署到任意静态托管（Nginx、OBS、GitHub Pages、Vercel）也只需要上传这一个文件。
